Task 3: Secure Coding

Project Title

Secure Login Authentication System

Project Description

This project demonstrates secure coding practices by reviewing and improving a basic Python login authentication program.

Objectives

- Identify security vulnerabilities.
- Perform code review.
- Use Bandit for static code analysis.
- Improve password handling.
- Implement a login attempt limit.

Technologies Used

- Python 3.12
- Visual Studio Code
- Bandit Security Scanner

Project Files

1. login.py – Original login program.
2. secure_login.py – Improved login program.
3. security_report.txt – Security findings and scan results.

Security Improvements

- Password hashing using PBKDF2.
- Salt usage.
- Secure password comparison.
- Maximum three login attempts.

Testing Results

- Correct login: Successful.
- Incorrect login: Rejected.
- Three incorrect attempts: Account locked.
- Bandit scan: No issues identified.

Conclusion

This project helped demonstrate code review, vulnerability identification, static analysis and secure coding practices in Python.
